Stella builds open-source tools for legal work: a legal workspace, legal data, text search
engines, identifier validation, anonymization utilities, or shared compliance
tooling.

Our public repositories focus on the practical infrastructure for law firms and legal
technology teams: fast text processing, reproducible supply-chain metadata,
consistent TypeScript/Rust tooling, and agent-readable project guidance.

Start with [`stella`](https://github.com/stella/stella) for the workspace, or browse
the smaller libraries if you need focused building blocks for legal data pipelines.

See [`stll.app`](https://stll.app) for our hosted legal workspace app.
