# Code of Conduct

Stay on the technical substance and assume the other person is contributing in
good faith.

Please:
- Critique the contribution, not the contributor.
- Accept that maintainers decide scope and direction, and that "no" is a normal
  outcome for a proposal.
- Read generously. This is an international project: most contributors are
  writing in a second language and working in a different legal system,
  timezone, and set of conventions. Terse phrasing is usually not hostility.

Please do not:
- Upload material you are not allowed to share.
- Publish private information of others without permission, especially regarding
  users, clients, or cases.
- Misrepresent your identity or affiliation. It is fine to be anonymous.
- Misuse the project for unsolicited advertising, spam etc.

## Reporting

If you wish to report a violation of this code of conduct, please do so in private via
email [conduct@stll.app](mailto:conduct@stll.app). Security vulnerabilities are not
conduct issues. Send those to [security@stll.app](mailto:security@stll.app); see
[SECURITY.md](https://github.com/stella/stella/blob/main/SECURITY.md).

Failure to follow the code of conduct may result in a ban from further contributions.

This applies in the project's repositories (issues, pull requests, commits, and
reviews), in the [Discord server](https://discord.gg/8dZjmVFjTK), and to anyone
representing the project in public.
